# MVP 0.3 — результат проверки

Контрольная точка перед изменениями: 2503468. AGENTS.md и архитектура v1.0 прочитаны и не изменены.

## Изменения

- Drop принимается и рабочей областью, и открытым диалогом. Всплывающий cancel от file input больше не закрывает диалог. Picker и drop дополняют множественный выбор; большие пачки разбиваются на безопасные запросы. Итог показывает количество загруженных, дубликатов и ошибок.
- Ctrl/Cmd, Shift на текущей странице, checkbox, выбор всех файлов папки (включая другие страницы), Esc и панель действий. Перемещение реально обновляет диск и SQLite.
- Один оригинал скачивается напрямую; несколько файлов или физическое дерево папки — потоковым ZIP. Оригиналы не меняются, временный ZIP не создаётся. Одинаковые имена в групповом архиве получают суффиксы.
- TrashEntry, скрытие объектов из обычной навигации, физическое перемещение во внешнюю корзину, подтверждение с проверкой актуального состава и восстановление без перезаписи. Окончательное удаление отсутствует.
- Project связан с Folder и MediaSet. Стандартный шаблон вынесен из UI, создаёт только шесть основных папок. Ошибки помечаются FAILED без полусозданного Project в SQLite; частичные физические папки сохраняются для безопасной проверки.

- lint и TypeScript — без ошибок; production build успешен.
