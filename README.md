# GART Media — MVP 0.2

Локальный файловый менеджер: Next.js / React / TypeScript, SQLite через Prisma, Sharp. Утверждённый трёхпанельный интерфейс подключён к реальным данным. Node.js 24 LTS, npm, Windows и локальный диск NTFS.

## Запуск

1. Установите зависимости: `npm install`.
2. Создайте локальный `.env` по `.env.example`. Каталог оригиналов должен уже существовать. Код, оригиналы и служебные данные должны быть в отдельных папках; оригиналы и служебные данные — на одном томе для атомарной записи без перезаписи.
3. Выполните `npm run dev`, откройте http://127.0.0.1:3000.
4. Нажмите Scan для индексирования существующих папок и изображений. Повторный Scan не дублирует записи. Альтернатива: `npm run scan` после `npm run db:setup`.

`dev` и `start` автоматически применяют миграции. Production: `npm run build`, затем `npm start`. Сервер слушает только 127.0.0.1; публикация в сеть и удалённый доступ не предусмотрены.

На Windows перед сборкой, обновлением зависимостей и `test:ui` остановите работающий сервер: иначе загруженная Prisma DLL может вызвать EPERM при генерации клиента.

## Хранение

- Оригиналы: `D:/Codex/App mediateka gartmemorial/GART_FILES`.
- SQLite, журнал операций, thumbnails и staging: `D:/Codex/App mediateka gartmemorial/GART_MEDIA_STATE`.
- Эти данные и `.env` не входят в Git. Резервируйте оба каталога данных при остановленном приложении.
- UI обращается только к серверным API. Файловые операции выполняет LocalStorageProvider.
- Загруженные оригиналы получают уникальное физическое имя; исходное имя сохраняется в SQLite. Содержимое не изменяется. Дубли SHA-256 пропускаются с указанием существующего расположения.
- Scan только читает оригиналы. Уже существующие физические копии индексируются по их путям, но не удаляются и не объединяются автоматически.
- Создание/переименование/загрузка используют блокировку и предварительный журнал AuditLog. При сбое между диском и SQLite незавершённая операция восстанавливается при следующем обращении; неоднозначное состояние блокирует операцию, а не исправляется удалением.

## Возможности и ограничения

Реальные папки, вложенное дерево и breadcrumbs; создание и переименование папки вместе с актуализацией путей потомков; поиск в выбранной папке, gallery/list, сортировка, страницы по 60 изображений; JPG/JPEG/PNG/WEBP, множественная загрузка и drag & drop; thumbnails и свойства файла.

Лимиты загрузки: 20 файлов, 50 МБ на изображение, 100 МБ на запрос, 80 мегапикселей. Анимированные изображения не поддерживаются. Неподдерживаемые/повреждённые изображения при Scan пропускаются с предупреждением. Символические ссылки и junction не обходятся. Показатель хранилища отображает занятость всего диска, не только медиатеки.

Во время операций приложения не переименовывайте те же папки в Проводнике. Внешнее перемещение ранее индексированных файлов, Missing/Relink и устранение таких расхождений — отдельный будущий этап. Для больших библиотек Scan синхронный и может занимать время; файловые операции сериализованы.

MediaSet предусмотрен моделью, но его редактор и Project пока не реализованы. Источник загрузки выбирается явно, по умолчанию UNKNOWN. Видео, теги, комментарии, коллекции, избранное, Trash, пользователи, Telegram, AI и облачные интеграции отключены. Автоматической публикации нет.

## Проверки

Для зависимости Prisma config закреплён deepmerge-ts 8.0.0 через overrides: исправление GHSA-ggr8-5vv4-36mx. Изменение проверяется миграциями, сборкой и тестами; при обновлении Prisma пересмотрите необходимость override.

`npm run lint`, `npm run typecheck`, `npm test`, `npm run test:ui`.

Браузерные проверки требуют Chromium (`npx playwright install chromium`). Тесты создают отдельные временные каталоги с синтетическими изображениями и SQLite, не используют рабочую медиатеку. UI-проверки включают перезапуск production-сервера и размеры 1440, 1920, 2560 и 390 пикселей. Временные данные сохраняются для диагностики. `GART_SCREENSHOT_DIR` задаёт папку снимков.

Постоянные правила: AGENTS.md и GART_MEDIA_ARCHITECTURE_v1.0_FOR_CODEX.md. Историческое описание UI-прототипа — docs/UI-v0.1.md; его синтетический demo-атлас больше не используется приложением.
