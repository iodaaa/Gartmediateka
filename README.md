# GART Media — UI v0.1

Локальный фронтенд-прототип по визуальному референсу. Next.js, React, TypeScript, Lucide и CSS. Требуется Node.js 24 LTS и npm.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:3000. `npm run build` проверяет production-сборку, `npm run typecheck` — типы. `npm run test:ui` запускает браузерные проверки (предварительно `npx playwright install chromium`).

## Границы прототипа

Поиск, фильтры, gallery/list, сортировка, избранное, выбор карточки, вкладки, описание, комментарии и создание демопапок/проектов работают в памяти браузера. Обновление страницы сбрасывает изменения. Загрузка и публикация файлов отключены. Карточка видео содержит только обложку.

В UI нет доступа к файловой системе, SQLite, ingest, checksum, Telegram, AI-анализу или облачным хранилищам. Реальные файлы будут храниться вне репозитория через StorageProvider на отдельном этапе.

`public/demo/architecture-sheet.png` — синтетическая иллюстрация исключительно для UI, не пользовательские материалы. `src/lib/demo-data.ts` содержит визуальные fixtures. Они не являются доменной моделью или реализацией backend.

Основные правила: AGENTS.md и GART_MEDIA_ARCHITECTURE_v1.0_FOR_CODEX.md.
